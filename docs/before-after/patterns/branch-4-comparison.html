The mechanic: 33-pattern catalogue + per-pattern detection cue (DOM signals, ARIA roles, anatomy hints). The page renders the subset that fires. Templates live in skills/extract-design-system/patterns/ as individual HTML snippets — each one uses var(--ink), var(--accent), var(--radius-card) so they inherit the extracted theme.
