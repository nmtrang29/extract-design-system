Claude Code skill

Extract a website's design system.

A Claude Code skill that turns any website URL into a polished, self-referential design-system reference page — plus a 400–800 line markdown spec cataloguing every detected token.

↗ GitHub repo SKILL.md designlang npm
Principle: a design-system page should be evidence of the system it documents. If the page uses 12px radii while documenting a 6px-only system, it contradicts itself. Snapping the chrome to the extracted tokens makes the page self-validating — every element you see is also a token in the reference table below it.
